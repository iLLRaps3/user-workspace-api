## 🎯 Project Overview

**GroqGenie** is an innovative AI-powered video generation platform that combines:
- **Groq's lightning-fast language models** for intelligent prompt optimization
- **MiniMax's advanced T2V technology** for high-quality video generation
- **Professional-grade controls** for cinematography and styling

## 🚀 Ready for Deployment

### Environment Variables Required:
```env
DATABASE_URL=postgresql://your-connection-string
GROQ_API_KEY=your-groq-api-key
MINIMAX_API_KEY=your-minimax-api-key
JWT_SECRET=your-jwt-secret-32-chars-minimum
NODE_ENV=production
```

### Quick Deploy Commands:
```bash
# Install dependencies
npm install

# Setup database
npm run db:push

# Start development
npm run dev

# Build for production
npm run build

# Deploy to Vercel
vercel --prod
```
